# 集成参考文件

这两个文件是从 `fbb_ws63` SDK 中复制的、已加入 beep / LED 示例配置的完整文件：

- `peripheral-CMakeLists.txt` → 对应 `src/application/samples/peripheral/CMakeLists.txt`
- `peripheral-Kconfig` → 对应 `src/application/samples/peripheral/Kconfig`

它们来自 HiSpark 开源 SDK（Apache-2.0），放在这里只用于对照你本地 SDK 需要增加的配置片段。
完整 SDK 体积很大，未包含在本仓库中。
